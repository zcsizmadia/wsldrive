---

### Why this exists rather than a redirect

GitHub redirects a moved repository's old path — until someone creates a
repository at that exact name, at which point the redirect stops and *their*
repository answers instead. The old name was left unowned, and anyone could
have taken it: inheriting every existing link, and every release-download URL
recorded in installs made before the move.

Occupying the name closes that. The cost is that old links now land here
instead of redirecting, which is why this page says plainly where to go.
